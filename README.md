# Rivals Workshop Assistant

An all-in-one tool for automating Rivals of Aether modding tasks


This may not work with versions of GMEdit made later than 2021.
A compatible version of GMEdit can be found [here](https://drive.google.com/file/d/1BbW6cyl17s_IVpG1LrGXLy2GTgoMmNPW/view?usp=sharing)

[Official docs](https://rivalslib.com/assistant/)
